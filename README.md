# DATA-COMPETITION-ISFEST-2026-Mapping-the-Demand-for-Electric-Vehicle-EV-Charging-Infrastructure-
- Mengidentifikasi faktor utama yang memengaruhi utilization_rate EV. - Membangun model prediksi dengan RMSE rendah. - Memberikan rekomendasi kapasitas dan ekspansi infrastruktur EV charging.  Menggunakan CRISP-DM dengan ensemble XGBoost, LightGBM, dan CatBoost melalui teknik weighted blending.
